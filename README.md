# Quiz-of-Us
Gioco di quiz per scoprire quanto ci si conosce

`index.html` è il gioco intero (un solo file): la versione per Sara, con El Falcon e il Crocco. È la stessa dell'artefatto «Quiz of Us».

Icone (`favicon-32.png`, `apple-touch-icon.png`, `icon-*.png`), `manifest.webmanifest` e `anteprima.png` (l'anteprima per WhatsApp, 1200×630) servono quando il gioco è su GitHub Pages: `https://marcocipriani08.github.io/quiz-of-us/`.

Senza rete: i caratteri sono dentro la pagina e `sw.js` tiene una copia del gioco, così dall'icona sulla Home si gioca anche offline (solo sulla copia di GitHub Pages).
